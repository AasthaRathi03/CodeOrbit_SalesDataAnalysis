# Sales Data Analysis with Pandas

## CodeOrbit Internship - Task 2

This project analyzes sales data using Python and Pandas to identify important sales metrics, product performance, category performance, regional performance and sales trends over time.

## Objectives

- Calculate Total Sales
- Calculate Average Order Value (AOV)
- Identify Top Products
- Analyze sales by Category
- Analyze sales by Region
- Analyze monthly and yearly sales
- Generate useful business findings

## Technologies Used

- Python
- Pandas
- Excel
- VS Code

## Dataset

The dataset contains sales transaction information such as:

- Order ID
- Order Date
- Customer
- Region
- Category
- Product
- Sales
- Quantity
- Discount
- Profit

## Analysis Performed

### Key Sales Metrics
- Total Sales
- Total Orders
- Average Order Value
- Total Quantity Sold
- Total Profit

### Product Analysis
Top products were identified based on total sales.

### Category Analysis
Sales, quantity, profit and number of orders were analyzed by category.

### Region Analysis
Sales performance was compared across different regions.

### Time Analysis
Monthly and yearly sales trends were calculated.

## Output

The analysis generates:

`sales_analysis_results.xlsx`

The Excel file contains separate sheets for:

- Top Products
- Category Analysis
- Subcategory Analysis
- Region Analysis
- Monthly Sales
- Yearly Sales
